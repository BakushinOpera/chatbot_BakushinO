# furniture/ — 家具贴图

现在是空的：房间里的床、书桌、衣柜、窗、椅子、床头柜、书架都是代码按灰模尺寸画的 SVG（风格见 `../manifest.json → room.style`）。

以后想换成自己画的贴图，这里放 PNG。每件家具需要先定下：
- 贴图的视角（房间视角是等距 30°、书桌视角是透视，两个视角各画一套）和每件家具在地板上的占地尺寸（厘米），见统一灰模 `greyBoxTest`（原型，不在仓库里；页面里的副本是 `pj1/web/room3d-scene.js`）；
- 锚点：家具「落地点」在图里的位置。

详细说明见 `../素材清单.md` 第 4 节。

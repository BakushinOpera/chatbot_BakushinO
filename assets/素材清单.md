# Phal 房间素材清单

房间页面用到的素材都在这个文件夹（`E:\ai\ds\assets`）。程序读的是同目录的 `manifest.json`，这份文档是写给你看的说明。
换素材的方法见最后一节；改完刷新房间页面（或重开桌面版）就能看到，不用改代码。

---

## 1. 文件夹

| 文件夹 | 里面是什么 | 现在的状态 |
|---|---|---|
| `character/` | 角色图（Q 版） | 4 张基础图（正面 / 侧面 / 背面 / 喝茶）+ `character/poses/` 里 21 张动作图（坐、躺、睡、站着做事，见 2.1），都在用 |
| `furniture/` | 家具贴图（床、书桌、衣柜……） | 空。现在家具是代码画的，见第 4 节 |
| `books/` | 书的贴图（封面、书脊） | 空。书是按参数画的，见第 5 节 |
| `props/` | 小物件贴图（毛绒玩具、盆栽……） | 空。同上 |
| `room/` | 房间本身（地板、墙、窗外风景） | `room/clutter/`：奶茶、零食贴图（见 4.1；`originals/` 是抠图前的原图）；`room/food/`：其他食物贴图（还没有）。其余空着 |
| `manifest.json` | 程序读的素材清单：角色图、位置、状态 | 在用 |

> 改文件夹名的话，要同时把 `manifest.json` 里所有对应的 `file` 路径改过来，否则房间里就没有角色（页面会提示「素材目录里还没有角色素材」或「角色素材加载失败」）。

## 2. 角色素材（现在在用的 4 张）

**大小统一：** 角色在房间里的身高是 **115 厘米**（`manifest.json → character.height_cm`）。房间墙高 240cm、床长 205cm、椅背 90cm，所以她大约是床长的一半多一点。
程序量每张图里「头顶到脚底」的像素高度，缩放到 115cm，所以不管每张图画多大、留多少空白，角色在房间里都一样大。**新图只要画得和现有的图比例一致（头身比、站姿），不用管像素尺寸。**

| 素材 | 文件 | 像素 | 用途 | 锚点（脚底中点，0~1） |
|---|---|---|---|---|
| 站立 | `character/正面.png` | 255×340 | 到位之后没有专属动作的状态；朝向镜头；带轻微的呼吸起伏 | `[0.5, 1.0]` 图片下边缘正中间 |
| 走路（水平） | `character/侧面.png` | 222×340 | 水平方向走路。图里角色朝左；往右走时左右镜像 | `[0.5, 1.0]` |
| 走路（往里） | `character/背面.png` | 253×340 | 往房间里面走；站在书桌 / 书架 / 衣柜前面对着它们 | `[0.5, 1.0]` |
| 喝茶 | `character/蓝发鲸鱼女仆茶饮五连帧.png` | 2172×724（5 帧横排，每帧约 434×724） | 「喝茶」状态的动作：站着喝茶，不绑定具体位置，在房间的空地上做。五帧循环：捧杯 → 小口喝 → 热气 → 眯眼笑 → 睁眼笑 | `[0.5, 1.0]`（每一帧自己的脚底中点） |

几点说明：

- **没有走路帧，所以走路 = 静态图 + 上下弹跳 + 平移**（`character.walk.mode = "static_bounce"`）。弹跳高度 3.2cm、频率 3.4 次/秒、速度 75cm/秒，都在 `manifest.json` 里能改。
- **喝茶图不是真透明**（棋盘格是画进像素里的）。`chroma: "auto"` 的意思是程序加载时自动把「和图片边缘相连的浅灰 / 白色」当背景抠掉。以后换成真透明的 PNG 会直接用，不抠。
- 朝向由走的方向决定：水平走用侧面图（往右走镜像）；往屏幕上方走用背面图；往屏幕下方走用正面图。

| `seat_draw` | 画画、做手工 | 房间 + 书桌 | 同上 |
| `seat_game` | 打游戏、整理相册、线上桌游 | 房间 + 书桌 | 同上 |

| `sofa_sit_phone` | 和朋友打电话 | 房间 + 书桌 | 同上 |
| `sofa_lie_video` | 刷视频、逛网店 | 房间 + 书桌 | 躺在沙发上（`sofa_lie`） |
| `sofa_lie_anime` | 追剧 | 房间 + 书桌 | 同上 |
| `bed_sleep` | 睡觉、午睡、生病、赖床 | 只有房间 | 躺在床上（新位置 `bed_lie`，头朝西靠枕头） |
| `stand_music` | 听歌 | 只有房间 | 床头柜旁 |
| `stand_wardrobe` | 收拾房间、试衣服 | 只有房间 | 衣柜前 |
| `stand_read` | 看书、整理书架 | 房间 + 书桌 | 书架前 |

- 坐 / 躺的图：`anchor` = 坐骨（躺着的是身体中心）在裁掉透明边以后的图里的位置，`height_cm` = 整张图折合多少厘米（按她头的大小和坐着的样子对过一遍：坐着 92~100、沙发上躺着 78、床上 110）。觉得大了 / 小了、坐歪了，改这两个数就行。

- 书桌视角里她坐在沙发上时，大半被书桌前的椅子挡着（场景就是这样摆的）。

## 3. 房间里的位置和状态

### 3.1 位置（`manifest.json → spots`）

坐标是**世界坐标**，单位厘米，和 `greyBoxTest` 的灰模一样：x 向西、y 向南、z 向上；房间 x −225（东墙）~ 365（西墙）、y 30（北墙）~ 360（南墙 = 窗墙），墙高 270。`face` 是方位角（从北往东量的度数：0 朝北 / 90 朝东 / 180 朝南 / 270 朝西），不写就面朝东南。
**每个位置都在空地板上、离家具至少 12cm，由 `tests/room3d_test.py` 检查。**（房间换成新灰模以后，旧的位置全部重新定过；`manifest.room.layout = "v5"`。）

| 位置名 | 坐标 (x, y) | 朝向 | 说明 |
|---|---|---|---|
| `desk` | 24, 118 | 朝北 | 书桌前（站着，桌子西端）；没有坐姿图又把 `seat.placeholder` 关掉时，写作业 / 画画站在这里 |
| `desk_seat` | −60, 142 | 25.6°（对准显示器） | **椅子上**（坐着，离地 48cm）；`seat: true`，只有声明了坐姿的状态才会来 |
| `sofa_sit` | −95, 322 | 朝北 | **沙发上坐着**（座面离地 45cm，背靠窗）；`seat: true` |
| `sofa_lie` | −95, 322 | 头朝东（`head: 90`） | **沙发上躺着**（身体沿沙发长边，占 100cm）；`seat: true`、`pose: lie` |
| `bookshelf` | −150, 262 | 朝东 | 书架西面（书架靠东墙、正面朝西） |
| `wardrobe` | 298, 112 | 朝北 | 衣柜前（衣柜门朝南） |
| `bed` | 252, 214 | 朝南 | 床边（北侧） |
| `nightstand` | 296, 209 | 朝西 | 床头柜旁（柜子在西墙边，她在柜子东面） |
| `window` | −100, 276 | 朝南 | 沙发前面，朝着窗；「趴窗边看雨」去这里 |
| `free_a` | 60, 215 | 155° | 空地：房间中间 |
| `free_b` | 170, 150 | 180° | 空地：衣柜和床之间 |
| `free_c` | −20, 255 | 160° | 空地：书架和床之间 |
| `free_d` | 88, 300 | 155° | 空地：落地灯旁 |

空地上的朝向都是朝南偏东：**背对书桌**，所以进书桌视角看到的是她的背面（房间里乱走的时候）；在房间视角里多半是正面或侧面。
`waypoints.edges` 是位置之间能走的路线（不穿过家具）。换状态时程序按这张图找最短路线走过去。改了位置坐标之后，跑一下 `tests/room3d_test.py`，它会检查位置有没有压到家具、路线有没有穿过家具、前后遮挡有没有错。

### 3.3 坐在书桌边 + 书桌上的笔记本（接口已留好，素材还没有）

**书桌上的笔记本**：`states.<状态>.desk` 写 `"B"` = 笔记本摊开（封面 + 左右两页，右手写字的角度）；不写 = `"A"` 笔记本合上、叠在书摞最上面。现在写作业、试图创作是 B。房间视角和书桌视角里的书桌一起变。

**坐姿**：`states.<状态>.seat = { "spot": "desk_seat", "anim": "seat_write" }` 表示这个状态下她坐在椅子上，用 `character.assets.seat_write` 这套图。不同状态用不同的 `anim` 名字就是「不同状态不同动画」（现在声明了的：写作业 / 试图创作 → `seat_write`，画画 → `seat_draw`，打游戏 → `seat_game`（玩电脑））。坐姿的图在 `manifest.json → character.assets` 里这样登记（`optional` = 文件还没有也不报错）：

```json
"seat_write": {
  "optional": true, "kind": "frames", "frames": 6, "durations_ms": [600, 600, 600, 600, 600, 600], "loop": true,
  "anchor": [0.5, 0.8], "z_cm": 48, "height_cm": 85,
  "views": {
    "room": { "file": "character/坐_写字_背面.png" },
    "desk": { "file": "character/坐_写字_正面.png" }
  }
}
```

- **按视角各一套**：房间视角（等距，从东南看）看到的是她的背面 / 右后侧，书桌视角（从北墙看）看到的是她的正面（下半身被桌面挡住，所以正面图画到腰以上就够）；只给一套的话两个视角共用。
- `anchor` 是**座面中心（坐骨）**在图里的位置（0~1），`z_cm` 是它离地的高度（座面高 48），`height_cm` 是整张图（头顶到图的底边）折合多少厘米高。
- **没有这套图时**：`manifest.seat.placeholder: true`（现在的设置）用站姿图临时顶替——书桌视角用正面图、房间视角用背面图，缩成 100cm、脚放在座面下面 25cm——这样她坐在椅子上、笔记本摊开，画面是完整的；真图一放进去就自动换掉。`placeholder: false` 就退回去站在书桌前（`desk` 位置）。
- 前后遮挡：她画在椅子座面和靠背**之后**、桌面和桌上的东西**之前**（书桌视角里桌面正好挡住她的下半身）。

## 4. 房间和家具（代码画的）

形状和尺寸按 `greyBoxTest` 里的**统一灰模**（房间 590 × 330 × 270cm）：L 形书桌顶在东北角（贴北墙 240 × 65 + 贴东墙 150 × 65），椅子对着显示器，书架（104 × 40 × 225，4 层）靠东墙、正面朝西；窗在南墙，窗下沙发 + 矮柜 + 落地灯；床在西南角，床头柜，衣柜贴北墙和西墙；西墙上有门洞（不画门）。`web/room3d-scene.js` 是灰模的副本，`web/room3d.js` 按风格把它画成 SVG。

**两个视角，同一份场景：** 房间视角（真等距 30° 轴，从东南看向西北，拆掉东墙 / 南墙 / 天花板）和书桌视角（透视，相机在北墙外面看向南偏东，铺满整个页面）。点房间视角里的书桌进书桌视角。

**画法：** SVG 逐块画出来（圆角轮廓 + 描边 + 按光照分面明暗），再按前后遮挡排序。三套风格，在 `manifest.json → room.style` 里选；页面顶栏有临时的 A / B / C 切换，选定后告诉我：

| 风格 | 特点 |
|---|---|
| `A` 水彩 | 暖奶油纸色、没有黑描边，边缘有颜料晕开的深色，线条略抖，带纸纹 |
| `B` 贴纸白边（**现在用的**） | 每件家具外面垫一圈白边，像贴纸 |

（C 线稿已删掉。页面顶栏可以在 A / B 之间切换。）

旧版（第 4 版灰模）的风格对比小样在 greyBoxTest/styles/index.html（读的是 pj1/web/iso.js，别把两个文件夹的相对位置挪开）。新房间的三套风格直接在房间页面里切换看。

家具的可点区域（点击打开对应的小物件列表）：床、床头柜、衣柜、**窗边**（窗下的矮柜 + 落地灯）、**沙发**、书架；书桌上靠北墙的一小块是**杂物区**（当日消耗品：她买来的零食、奶茶，至少放半小时、最迟睡前收掉；系统自己管，不在设置的区域表里）；**书桌**（桌面、椅子、桌上的东西）点一下进书桌视角。区域的名字和小物件分类平时藏着，鼠标移上去才显示。

- 三套风格里贴图本身不变，只是 A 水彩略泛黄、C 线稿降了饱和度，免得和周围差太多。

### 4.2 窗外天气（书桌视角，代码画的动画）

窗外分层画：天空渐变 → 远云（慢慢飘）→ 树和坡 → 远处的雨 / 雪 → 近处的雨 / 雪、窗台溅水、窗台积雪 → 玻璃上的雨滴和水痕 → 室内。每层有自己的速度、透明度、模糊（整体有一点景深）。下雨偶尔闪电，屋里跟着亮一下。

- 配色按「时段（清晨 / 白天 / 黄昏 / 夜晚）× 天气（晴 / 阴 / 雨 / 雪）」的配色表，按钟点在相邻时段之间混合，每小时一档。
- 屋里的光也跟着变：雨天整体变暗、偏冷；晴天太阳从南窗斜射进来，地上（太阳低的时候还有桌面上）有窗格形状的亮斑，空气里有淡淡的光柱；夜里和阴雨天落地灯、显示器有微光。
- 天气效果已经定稿，参数用出厂值（调试面板、预设都删掉了）。想再调的话跟我说。
- 房间视角不跑动画（窗墙是拆掉的），只有屋里的光色和地上的亮斑。
- 卡的话：设置 → 她的房间 → 画面 → **渲染精度**（高 / 中 / 低）。
- 想换成自己画的天空 / 云 / 雨的贴图：先和我说，再定每层的尺寸。

## 5. 书和小物件（参数决定外观）

书和小物件**没有贴图**，每一件都带一组外观参数，由同一个函数画出来，所以封面和书脊永远一致、以后加新种类也只是加参数。

### 5.1 书的外观参数（`look`）

| 参数 | 含义 |
|---|---|
| `main` | 主色（书皮底色） |
| `accent` | 点缀色（花纹、横带、徽记） |
| `ink` | 书名颜色 |
| `pattern` | 花纹：`plain` 素色 / `stripes` 竖条 / `dots` 点点 / `band` 横带 / `grid` 格子 / `diamond` 菱形 / `wave` 波纹 |
| `w` | 书脊宽（书的厚度，厘米，1.2~6） |
| `h` | 书高（厘米，14~34） |
| `cw` | 封面宽（厘米） |
| `tl` | 书脊上书名的排版：`v` 竖排 / `h` 横排（转 90°）/ `s` 两列竖排 |
| `tf` | 书名字体风格：`serif` 衬线 / `sans` 无衬线 / `round` 圆体 |
| `tp` | 竖排时书名的位置：`t` 靠上 / `c` 居中 / `b` 靠下 |
| `band` | 书脊上下横带的条数（0~2） |
| `emblem` | 封面徽记：`none` / `dot` / `star` / `leaf` / `line` |

- **导入的书**（阅读器里的书）：外观参数由它的默认封面的颜色和样式生成（`app/booklook.py → default_look`）。
- **Phal 自己买的书**：购买时随机生成书名、作者和外观参数（`random_look`），是不能阅读的摆设书。
- **右键一本书 → 修改书籍详情**：改书名、作者（摆设书还能改备注、重新随机外观、收纳 / 放回书架、和收纳篮里的书交换、删除）。导入的书改的是阅读器书架里这本书的名字。
- **书上最多显示书名的前 8 个字**（书脊、封面、列表），完整书名只在修改详情里看得到。
- 房间书架：书脊朝外，显示这个书架上的全部书；点一本书看到封面。书架管理里每本书是横版小卡片（封面 + 书名前 8 个字）。阅读器里的原书架只显示你导入的书，没有变化。

### 5.2 书架放不下时

书架 50 本 → 地上堆 20 本（横着，略显凌乱，在贴北墙那条书桌的下面）→ 还放不下时，Phal 把**她自己买的书**（最新的 3 本除外）每次 10 本收进**收纳篮**。收纳篮里的书不对外展示，但一直保存；你可以在书架管理里随时换它们和书架上的摆设书。三个数字在设置里改：书架容量 / 地上容量 / 每次收纳数。

### 5.3 小物件的外观参数

`shape`（形状：`plant` 盆栽 / `plush` 毛绒玩具 / `stack` 书堆 / `cloth` 叠衣服 / `device` 小设备 / `lamp` 台灯 / `box` 盒子）、`color`、`accent`、`size`（0.6~1.5 倍）、`pot`（盆栽的花盆颜色）。
同一件东西每次生成的样子一样（按名字和编号定）。

## 6. 还缺的素材（有了就能让她更生动）

现在用「静态图 + 弹跳」凑合的部分，按重要程度排：

1. **走路帧**：侧面 4~6 帧（可镜像）、背面 4 帧、正面 4 帧。有了之后把 `character.walk.mode` 改成 `frames`，在 `assets` 里加 `walk_side` / `walk_back` / `walk_front`（`kind: frames`）。
2. **坐着**：坐在椅子上（书桌前），**房间视角（背面 / 右后侧）和书桌视角（正面，腰以上）各一套**，写字、画画、玩电脑（打游戏）各一个动作。接口已经留好（见 3.3），现在是用站姿图临时顶替。
3. **躺着**：躺在床上的一张图（睡觉、午睡、生病）。现在是站在床边冒「zzz」。
4. **看书**：站在书架前翻书、或坐着看书。
5. **听歌 / 打游戏 / 刷视频 / 追剧**：各一张静态图（拿着耳机 / 手柄 / 手机……）就够用，不需要动画。

每个新素材登记在 `manifest.json → character.assets` 里：写 `file`、`anchor`（脚底中点）、`use`；状态在 `states` 里加 `"anim": "素材名"` 就会在到位后播放。

## 7. 怎么替换素材

**角色图：** 把新图放进 `character/`（或新建文件夹），文件名和原来一样就直接替换；换名字的话改 `manifest.json` 里对应的 `file`。要求：

- PNG，**透明背景最好**（不是透明的也行，浅灰 / 白色背景会被自动抠掉，但边缘可能不干净）。
- 脚底贴着图片下边缘、水平居中（锚点是 `[0.5, 1.0]`）；不是的话改 `anchor`。
- 头顶到脚底的像素高度随便，程序会统一缩放到 115cm。
- 帧动画：多帧横着排成一张图，在 `manifest.json` 里写 `frames` 帧数、`durations_ms` 每帧时长。

**位置：** 改 `manifest.json → spots` 的坐标，然后跑 `tests/room3d_test.py` 看有没有压到家具。

**风格：** 改 `room.style`。

**缓存：** 素材目录有变化时，页面会自动带新的版本号重新加载，不用清缓存。

## 8. 还需要的动画素材清单

> v10.2：下面第一张表里的坐 / 躺图（以及床上睡觉、听歌、收拾衣柜、看书）已经有了静态图，在 `character/poses/`（见 2.1）。还能补的：多帧动画（现在是单张静态图）、走路帧，以及 v9 / v10 新状态的专属动作（练字、做手工、拼图、跳绳 / 瑜伽、拆快递、一个人在食物桌边吃饭、边做事边吃东西……）。

先看两个视角的拍法，每个动画都要按这两个视角各画一套（只画一套的话两个视角共用，但会不太对）：

| 视角 | 怎么看 | 她朝向画面的哪边 |
|---|---|---|
| **房间视角** | 真等距（30° 轴），从房间的东南角往西北看，高高在上 | 在书桌椅子上：面朝北偏东 26°（对着显示器）→ 我们看到她的**背面 / 右后 3/4**；在沙发上坐着：面朝北 → 看到**右侧**（画面右上）；躺在沙发上：头朝东 = 画面**右下** |
